# 美术资源生成说明

本目录依据 `docs/未实现功能详细设计与美术资源需求.md` 制作，视觉基准取自当前 Bubble 项目的球体、精灵、特效与 UI 资源。资源为待评审的生图交付，不直接写入 `assets/`。

## 已覆盖范围

- 现有近似功能补齐：漩涡受阻、多目标救援、Fever、两种彩虹球、整行锁链、两种闪电球、二圈炸弹。
- 棋盘特殊球：蜜蜂骷髅、地雷、鱼卵三分支、风眼、礼盒、积雪球、透明球、染色蛋、幽灵、黑洞、繁殖球、城堡结构、受控随机预告。
- 附着机关：迷雾、树叶、毒、感染、额外墨汁、变色、冰凌、蜘蛛/蜘蛛茧、气泡盾/棉絮盾。
- 场景特殊物：乌龟、瓢虫、彩云、风沙、雪雾、底部保护罩、雪罩、毒液网、冰凌网、节日护送角色与雪屋。
- 主玩法模式：下压模式、首发怪物全状态、城堡 Boss、自由幽灵、节日护送。
- 缺失玩家道具：全局融冰、望远镜、芭蕉扇、底部保护罩、防蜂罩、两种防护网、加时、海草眩晕、收纳口袋、两种闪电球、单双行清除、上推三行、二圈炸弹、同色清屏。

## 目录约定

- `ball/`：棋盘球体与特殊对象，主要为 140x140 RGBA。
- `attachment/`：单球附着叠层，主要为 140x140 RGBA。
- `effect/`、`effects/`：局部 VFX 与 Shader 用噪声图。
- `animation/`：独立序列帧及可直接切片的合并图集；常规帧为 256x256，图集为 1024x768。
- `props/`：局内道具图；`ui_props/` 为 UI 生命周期副本。
- `preview_balls/`：关卡预览和说明界面副本。
- `mode/`、`monster/`、`castle/`、`holiday/`、`moving/`、`scene/`、`weather/`：专用模式、角色、结构和场景资源。
- `rescue_target/`：七名救援目标角色头像。

## 动画图集切片

- 4x3 图集：单帧 256x256，顺序为从左到右、从上到下。
- `animation/bee_attack/` 与 `animation/mine_explosion/`：各 12 帧。
- `animation/fish_actions/`：墨鱼、大嘴鱼、染色鱼各 4 帧。
- `animation/reactive_actions/`：礼盒、积雪球、透明球各 4 帧。
- `animation/hazard_actions/`：染色蛋、黑洞、繁殖球各 4 帧。
- `animation/attachment_actions/`：断链、蜘蛛网、气泡盾各 4 帧。
- `animation/attachment_fx/`：迷雾、感染、冰凌各 4 帧。
- `animation/moving_actions/`：乌龟、瓢虫、彩云各 4 帧。
- `animation/mode_actions/`：城堡开箱、幽灵获救、随机揭示各 4 帧。
- `animation/holiday_actions/`、`animation/monster_actions/`、`animation/ink_fade/`：角色关键状态与墨汁淡出图集。

## 非生图交付

需求中的 `.anim`、`.effect`、音频和 Cocos `.meta` 不属于图片生成内容，因此没有伪造。资源确认后导入 `assets/` 时，应由 Creator 生成 `.meta`，再按运行时需求制作动画剪辑、材质与音频。

## 校验结果

- 全部 PNG 可读取，统一为 RGBA。
- 透明资源四角 alpha 均为 0。
- 未发现空白帧、损坏图片或临时切片目录。
- UI 副本来自已确认主体资源，避免同一图标重复生成产生造型漂移。
