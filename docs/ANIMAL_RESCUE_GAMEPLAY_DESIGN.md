# 拯救动物玩法设计

## 1. 文档状态

- 状态：玩法与技术设计稿，尚未实现
- 适用项目：Bubble 泡泡龙局内玩法
- 玩法类型：以中心动物为唯一支撑锚点的旋转泡泡棋盘
- 本文档只定义玩法、配置、运行时边界、表现规则和验收标准，不代表已经修改玩法代码、关卡配置或资源

## 2. 设计目标

### 2.1 核心目标

1. 动物固定在棋盘中心，周围泡泡相互连接，所有有效支撑最终必须连通到动物。
2. 完全移除普通棋盘依赖顶部行、锁定球或虫洞提供支撑的规则。
3. 发射泡泡吸附后，根据真实入射方向、命中位置到动物的距离以及当前泡泡簇惯量，让受支撑泡泡围绕动物产生受力旋转。
4. 泡泡簇可以停留在任意角度，后续瞄准、碰撞和吸附仍然保持准确。
5. 消除连接点后，无法连通动物的泡泡必须在本次发射周期内立即进入正常掉落链路。
6. 旋转角度、支撑关系、吸附结果和胜负判定全部由玩法状态决定，渲染层不得建立独立结果。
7. 关卡配置、远程压缩包、编辑器和验证器保持 Fail-Fast，不通过默认值或兼容分支掩盖缺失配置。

### 2.2 非目标

首版不包含以下行为：

- 不模拟泡泡之间的弹簧、挤压或逐球刚体碰撞。
- 不让中心动物随泡泡簇持续旋转或移动。
- 不把顶部边界作为可吸附表面。
- 不使用普通棋盘的顶部空槽崩塌、行推进和危险线规则。
- 不允许锁定球、虫洞成为额外支撑锚点。
- 不在旋转过程中重新排列泡泡的格子坐标。
- 不在运行时为缺失的动物、旋转参数或锚点位置补默认值。
- 首版不支持一关多个动物或多个独立旋转泡泡簇。

## 3. 核心玩法模型

### 3.1 动物锚点

动物占用一个保留的六边形格子。该格子只用于定义：

- 动物的逻辑位置。
- 泡泡簇的旋转中心。
- 支撑搜索的根节点。
- 动物视觉节点的定位。

动物格不能放置普通泡泡或特殊实体，也不能成为发射泡泡的吸附目标。

动物周围六个相邻格为第一层支撑位。第一层泡泡继续支撑外层相邻泡泡，最终形成一张以动物为根的六边形连接图。

示意：

```text
        ○ ○
      ○ ○ ○
    ○ ○ 🐾 ○ ○
      ○ ○ ○
        ○ ○
```

### 3.2 唯一支撑规则

动物模式中的支撑种子只能来自动物格的六个邻接格。

```text
seeds = 动物六个邻接格中当前存在的泡泡
supported = 从 seeds 沿六方向泡泡连接执行 BFS
floating = 棋盘全部泡泡 - supported
```

规则：

- 棋盘第 0 行不提供支撑。
- 锁定球不提供支撑。
- 虫洞不提供支撑。
- 动物格本身不进入泡泡列表。
- 普通球、允许进入动物模式的障碍球和特殊球都按所在格参与连接。
- 动物六个邻接格全部为空时，所有剩余泡泡均失去支撑。
- 每次棋盘结构发生变化后都必须执行动物支撑搜索。
- 无支撑泡泡必须在当前发射周期内移除并注册掉落，禁止延迟到下一次发射。

### 3.3 刚体旋转

受支撑泡泡共享同一个旋转角度。泡泡之间的相对位置、六边形邻接关系和格子坐标保持不变。

每个泡泡仍然使用 `odd-r-hex` 的 `row/col` 作为权威拓扑坐标。旋转只改变局部棋盘到世界坐标的变换，不改变格子数据。

这样能够保证：

- 泡泡间距不会因浮点误差逐渐漂移。
- 同色匹配继续使用离散邻接关系。
- 支撑搜索不依赖当前视觉角度。
- 棋盘可停留在任意角度。
- 后续发射可以准确命中已经旋转的泡泡。

## 4. 坐标系统

### 4.1 局部坐标

继续使用现有 `BoardLayout` 计算每个 `row/col` 的原始六边形位置。

设：

```text
Pcell = 格子的原始六边形位置
Panchor = 动物格的原始六边形位置
Plocal = Pcell - Panchor
```

`Plocal` 是泡泡相对动物中心的局部坐标，在整个关卡中保持不变。

### 4.2 世界坐标

设动物世界坐标为 `Panimal`，当前棋盘旋转角为 `θ`：

```text
Pworld = Panimal + Rotate(Plocal, θ)
```

所有玩法层几何查询必须读取该世界坐标，包括：

- 发射球与棋盘泡泡碰撞。
- 瞄准轨迹预测。
- 吸附候选格筛选。
- 爆炸和范围效果中心。
- 消除、碎裂和掉落起点。
- 引导、高亮和受力提示定位。

### 4.3 世界坐标转局部坐标

发射球碰撞点和入射方向需要转换到动物局部坐标，才能继续使用六边形格子邻接规则：

```text
Plocal = Rotate(Pworld - Panimal, -θ)
Vlocal = Rotate(Vworld, -θ)
```

碰撞检测使用世界坐标，吸附格选择使用转换后的局部接触点和方向。

### 4.4 权威状态

玩法快照至少保存：

```text
animalRescue.anchorCell
animalRescue.worldCenter
animalRescue.rotationAngleRad
animalRescue.angularVelocityRadPerSec
animalRescue.rotationPhase
animalRescue.rotationRevision
```

渲染层只读取快照，不自行累加角度或根据动画结果回写玩法状态。

## 5. 发射、碰撞与吸附

### 5.1 发射期间的棋盘状态

只有在以下状态全部结束后才允许再次瞄准和发射：

- 上一次泡泡簇旋转。
- 匹配与特殊效果。
- 无支撑掉落注册。
- 仍会修改棋盘结构的延迟效果。
- 胜负结算。

发射球飞行期间泡泡簇保持当前角度，不继续自由旋转。这样能够保证瞄准预测、真实碰撞和吸附格一致。

### 5.2 合法吸附

发射泡泡的目标格必须满足：

- 目标格为空。
- 目标格不是动物保留格。
- 目标格与一个当前受支撑泡泡相邻。
- 发射球从当前入射方向能够实际到达目标格。
- 目标位置与已有泡泡不存在重叠。
- 目标位置位于关卡允许的旋转半径内。

碰撞后先将接触点和方向转换到动物局部坐标，再从被碰泡泡的六个邻接格中选择最符合接触法线的合法格。

运行时预测为可吸附，但最终没有合法吸附格时必须直接报错，说明预测和真实碰撞算法不一致。禁止回退到顶部格或任意空格。

### 5.3 顶部开放边界

动物模式没有顶部吸附。

如果发射泡泡经过墙壁反弹后仍未命中泡泡簇，并越过顶部开放边界：

- 本次发射计为射失。
- 消耗一个发射球。
- 不增加棋盘泡泡。
- 不产生旋转冲量。
- 不执行顶部吸附。
- 结算完本次发射后恢复输入或判断球数耗尽。

射失是明确的玩法结果，不是异常兜底。

### 5.4 墙壁反弹

继续支持左右墙反弹。受力计算必须使用实际碰撞前的最终飞行方向，而不是最初瞄准方向。

因此反弹射击可以主动改变泡泡簇的旋转方向。

## 6. 受力旋转模型

### 6.1 冲量记录

发射球真正接触泡泡簇时立即记录：

```text
impactPointWorld
incomingDirectionWorld
collidedCell
attachmentCell
shotSequence
```

记录必须发生在同色消除和特殊效果修改棋盘之前。即使发射球随后形成匹配并消失，本次碰撞产生的冲量仍然有效。

### 6.2 力矩

设：

```text
r = impactPointWorld - animalWorldCenter
J = normalize(incomingDirectionWorld) × projectileImpulse
```

二维力矩为：

```text
torque = r.x × J.y - r.y × J.x
```

若屏幕坐标系约定逆时针为正：

- `torque > 0`：逆时针旋转。
- `torque < 0`：顺时针旋转。
- `torque ≈ 0`：几乎不旋转。

该公式同时包含距离和角度影响：

```text
|torque| = |r| × |J| × |sin(α)|
```

其中 `α` 是半径方向与入射方向的夹角。

结果：

- 正对动物中心发射时，切向分量接近零，旋转很小。
- 命中外圈时，力臂更长，旋转更明显。
- 擦着泡泡簇边缘发射时，切向分量最大。
- 左右对称入射会产生大小相近、方向相反的旋转。

### 6.3 转动惯量

完成消除和支撑扫描后，使用仍受动物支撑的泡泡计算转动惯量：

```text
I = animalCoreInertia + Σ(mass_i × distance_i²)
```

首版所有允许进入动物模式的泡泡使用相同质量。暂不为颜色球、冰球和石球建立不同质量，避免玩法规则难以理解。

`animalCoreInertia` 用于：

- 防止剩余泡泡很少时角速度过大。
- 表达中心动物和旋转连接结构的基础惯量。
- 让末盘旋转仍然可控。

初始角速度：

```text
ω0 = clamp(torqueScale × torque / I, -maxAngularSpeed, maxAngularSpeed)
```

### 6.4 阻尼

旋转使用指数衰减：

```text
ω(t) = ω0 × e^(-damping × t)
θ(t) = θ0 + ω0 / damping × (1 - e^(-damping × t))
```

优点：

- 不同设备帧率下的最终角度一致。
- 转动开始快、停止自然。
- 不依赖逐帧累加得到最终结果。
- 暂停和恢复时可以从明确状态继续。

当满足任一条件时停止：

- `|ω| <= stopAngularSpeed`。
- 达到 `maxDurationSec`。
- 本次累计转角达到 `maxStepAngleDeg`。
- 棋盘已完全清空。

停止时只把角速度归零，保留当前任意角度，不吸附到 60° 倍数。

### 6.5 推荐首轮参数

| 参数 | 推荐初值 | 说明 |
| --- | ---: | --- |
| `projectileImpulse` | 1 | 固定发射速度下使用归一化冲量 |
| `torqueScale` | 1 | 全局旋转力度 |
| `animalCoreInertia` | 8 | 约等于8个普通泡泡质量单位 |
| `maxAngularSpeedDeg` | 110 | 最大角速度 |
| `angularDamping` | 5 | 指数阻尼 |
| `stopAngularSpeedDeg` | 2 | 停止阈值 |
| `maxStepAngleDeg` | 45 | 单次最大累计转角 |
| `maxDurationSec` | 0.9 | 单次最长旋转时间 |
| `tangentialDeadZone` | 0.05 | 过滤几乎径向的浮点抖动 |

上述值是首轮调试起点。正式数值应通过径向、斜向、切向、内圈和外圈五组实机样本调整。

## 7. 单次发射结算流程

```text
aiming
  → projectile_flying
  → impact_captured
  → attachment_committed
  → match_and_special_resolution
  → animal_support_scan
  → floating_drop_registration
  → animal_cluster_rotation
  → outcome_resolution
  → aiming
```

详细顺序：

1. 玩家完成瞄准并发射。
2. 发射球按现有弹道与左右墙反弹规则飞行。
3. 命中泡泡簇时记录碰撞点、最终入射方向和待计算冲量。
4. 将接触点转换到动物局部坐标，原子提交吸附格。
5. 执行同色匹配、解冻、爆炸、钥匙等当前允许的结构变化。
6. 所有同步结构变化完成后，从动物邻接格执行支撑搜索。
7. 移除无支撑泡泡，并在当前周期注册正常掉落。
8. 使用剩余受支撑泡泡计算惯量和初始角速度。
9. 受支撑泡泡簇围绕动物旋转；掉落泡泡不再跟随旋转层。
10. 旋转、掉落和延迟效果全部稳定后判断获救、球数耗尽或恢复瞄准。

### 7.1 无匹配发射

即使没有形成同色匹配，也要完成以下步骤：

- 提交吸附。
- 执行动物支撑状态检查。
- 计算本次碰撞产生的旋转。
- 锁定输入直到旋转结束。

### 7.2 发射球被消除

发射球吸附后立即形成匹配并被移除时：

- 使用碰撞前记录的冲量。
- 使用消除后的受支撑泡泡集合计算惯量。
- 如果仍有泡泡，则继续旋转。
- 如果棋盘已经清空，则跳过空旋转并进入获救流程。

### 7.3 延迟特殊效果

如果特殊效果会在延迟后继续修改棋盘结构：

- 碰撞冲量先保存。
- 完成全部结构变化和最终支撑扫描后再启动正式旋转。
- 可以在碰撞瞬间播放不改变逻辑角度的短促压缩或震动。
- 禁止在正式旋转过程中并行修改格子拓扑。

## 8. 掉落规则

### 8.1 当前周期立即掉落

删除桥接泡泡后产生的无支撑分支，必须在本次发射结算中完成：

```text
findFloatingCells
  → removeFloatingCells
  → registerDrops
```

禁止出现棋盘状态已经无支撑，但渲染仍保留到下一次发射的情况。

### 8.2 脱离旋转层

泡泡进入掉落系统时：

1. 读取脱离瞬间的世界坐标。
2. 从受支撑泡泡渲染层移除。
3. 以世界坐标放入掉落层。
4. 后续只由 `FallingMarbleSystem` 驱动。

不得继续继承旋转父节点，否则会同时受到旋转和重力位移。

### 8.3 切向初速度

为了表现被旋转甩出，掉落泡泡可以继承切向速度：

```text
Vtangent.x = -angularVelocity × radiusVector.y
Vtangent.y =  angularVelocity × radiusVector.x
Vinitial = Vtangent × tangentVelocityScale
```

随后再由正常重力、精灵碰撞和罐子收集系统处理。

`tangentVelocityScale` 必须显式配置或使用统一玩法常量，不根据缺失值自动补全。

## 9. 棋盘边界与安全区域

### 9.1 禁用普通棋盘推进

动物模式明确禁用：

- 顶部行支撑。
- 顶部可吸附边界。
- 顶部空槽全盘崩塌。
- `BoardViewportSystem` 的行推进和可见行调整。
- `reach_danger_line` 失败条件。
- 依赖 `dropInterval` 的普通棋盘下移。
- 依赖 `initialDropSpaceRows` 的开局和复活空间恢复。

这些字段不应保留一个无意义数值来满足旧校验，应改为动物模式专用配置合同。

### 9.2 旋转包围圆

动物位置和泡泡最大局部半径在关卡加载时执行严格验证：

```text
requiredRadius = max(distance(animal, occupiedCell)) + bubbleRadius
safeRadius = min(
  animal到左墙距离,
  animal到右墙距离,
  animal到顶部开放边界距离,
  animal到炮台禁区距离
)

requiredRadius <= safeRadius
```

旋转不会改变包围圆，因此配置通过后，泡泡簇在任意角度都不会进入墙外或炮台区域。

超出安全半径的关卡必须加载失败，禁止运行时缩放棋盘或把动物位置自动改到其他位置。

## 10. 胜负与目标

### 10.1 胜利目标

新增主目标：

```json
{
  "type": "rescue_animal",
  "value": 1
}
```

获救条件：

- 棋盘已没有受支撑泡泡。
- 无支撑泡泡已经全部从棋盘移除并注册掉落。
- 没有待执行的结构变化。
- 没有待执行的旋转。
- 动物尚未触发过获救。

满足条件后进入 `won_pending`，等待当前表现链完成，再播放动物获救动画并进入胜利结算。

### 10.2 最后连接点

如果最后一个直接连接动物的泡泡被消除：

- 所有外围分支立即失去支撑。
- 所有外围分支在当前周期一起进入掉落系统。
- 不再启动没有受支撑对象的旋转。
- 掉落表现完成后触发动物获救。

### 10.3 失败

首版使用 `shot_limited`：

- 剩余发射数为0时，不立即抢占当前结算。
- 必须等待本次消除、掉落、延迟效果和旋转完成。
- 如果结算后动物已经获救，则胜利优先。
- 如果仍有受支撑泡泡，则进入球数耗尽流程。

动物模式不使用危险线失败。

## 11. 表现设计

### 11.1 渲染层级

建议节点结构：

```text
GameView
  animalRescueRoot
    animalNode
    supportedClusterRoot
      boardBubbleNodes
    impactFxRoot
    torquePreviewRoot
  projectileRoot
  fallingMarbleRoot
```

规则：

- `animalNode` 固定在中心，不挂在旋转节点下。
- `supportedClusterRoot` 只包含仍受动物支撑的棋盘泡泡。
- `projectileRoot` 使用世界坐标，不随棋盘旋转。
- `fallingMarbleRoot` 使用世界坐标，不随棋盘旋转。
- 碎裂、爆炸和消除特效必须使用事件发生时的世界坐标。

### 11.2 动物反应

动物作为固定支点，不参与持续旋转，但可以播放轻量受力反馈：

- 命中瞬间朝受力反方向偏移2至4像素。
- 根据力矩方向轻微反向倾斜，最大3°。
- 强冲量时播放惊讶、眨眼或抓紧动作。
- 泡泡全部清空后播放释放、舒展和庆祝动画。

动物反馈只能是表现，不改变逻辑旋转中心。

### 11.3 旋转反馈

- 命中瞬间播放80至120毫秒的泡泡簇压缩或轻震。
- 正式旋转使用物理阻尼曲线，不使用固定时长匀速旋转。
- 旋转强度越大，碰撞音效和支点拉伸效果越明显。
- 音效按轻、中、重三档选择，不需要连续修改音调。
- 掉落分支继承切向速度，强化“被甩出”的感觉。

### 11.4 瞄准受力提示

轨迹预测确定碰撞点后，在动物外围显示弧形箭头：

| 强度 | 表现 |
| --- | --- |
| 轻 | 短蓝色弧线 |
| 中 | 黄色中长度弧线 |
| 重 | 红色长弧线 |

箭头方向表示顺时针或逆时针。几乎径向入射时不显示箭头。

提示只显示预测结果，不参与真实冲量计算。

### 12.3 严格校验

`animal_rescue` 关卡必须满足：

- `animalRescue` 显式存在且为对象。
- `animalId` 为非空字符串。
- `asset` 为合法且可加载的资源路径。
- `anchorCell.row/col` 为有效蜂窝格。
- 动物格在 `layout` 中必须为 `.`。
- 动物格不能存在 `specialEntities`。
- `worldCenter.x/y` 为有限数值。
- `rotation` 所有字段显式存在并在合法范围内。
- `winConditions` 必须且只能包含一个 `rescue_animal` 主目标。
- `rescue_animal.value` 必须为1。
- 初始至少有一个泡泡直接邻接动物。
- 初始全部棋盘泡泡必须能连通到动物。
- 顶部行可以为空，不执行顶部锚点校验。
- 旋转包围圆必须位于安全区域。
- 不允许配置普通棋盘推进和危险线规则。
- 首版不允许配置多个动物。
- 首版不允许配置不兼容特殊实体。

普通关卡不得出现 `animalRescue` 字段。字段与关卡类型不一致时直接报错。

### 12.4 Schema与远程包

实施时必须同步：

- `LevelConfigLoader`
- `LevelBoardSupportValidator`
- `LevelPackCompactCodec`
- 本地关卡生成器
- 远程关卡生成器
- 远程包 manifest 的字节数与 SHA-256
- 关卡内容验证器
- 关卡编辑器导入、编辑、保存和云草稿同步
- 玩法生成包

禁止只修改输出 JSON，也禁止在解码器中把缺失动物配置补成默认值。

## 14. 运行时系统边界

### 14.1 `AnimalRescueRotationSystem`

新增独立系统负责：

- 加载并验证动物模式运行参数。
- 保存旋转角度和当前旋转阶段。
- 记录本次碰撞冲量。
- 根据当前受支撑泡泡计算转动惯量。
- 计算初始角速度、停止时间和最终角度。
- 提供局部坐标与世界坐标转换。
- 生成旋转快照和一次性事件。
- 在暂停、恢复、重开和销毁时维护完整状态。

该系统不负责：

- 同色匹配。
- 支撑搜索。
- 删除棋盘泡泡。
- 掉落物理。
- Cocos 节点动画。

### 14.2 `SupportSystem`

支撑系统增加显式策略：

```text
top_anchor
animal_anchor
```

普通模式继续使用顶部、锁定球和虫洞规则。动物模式只使用动物邻接格。

禁止通过“先按普通模式扫描，再额外保留动物附近泡泡”的叠加方式实现，否则会留下多个支撑来源。

### 14.3 `BubbleGrid`

需要增加：

- 动物保留格检查。
- 当前旋转角下的格子世界坐标。
- 世界坐标到动物局部坐标的转换。
- 旋转棋盘的射线碰撞。
- 动物模式专用吸附候选筛选。
- 禁止顶部吸附。
- 安全半径计算。

格子拓扑、颜色、特殊字段和邻接算法继续保持局部六边形权威。

### 14.4 `TrajectoryPredictor`

动物模式预测：

- 不计算 `topAttachY`。
- 只检测左右墙、泡泡簇和顶部射失边界。
- 使用旋转后的格子世界坐标。
- 输出实际碰撞前的最终方向。
- 输出吸附格和吸附中心。
- 输出预测力矩方向和强度等级。

### 14.5 `GameManager`

`GameManager`负责把当前发射结算串成单一事务：

```text
记录冲量
→ 吸附
→ 同步结构变化
→ 动物支撑扫描
→ 掉落注册
→ 启动旋转
→ 等待稳定
→ 胜负判断
```

不能由渲染回调决定何时扫描支撑或开放下一次发射。

### 14.6 `BoardViewportSystem`

动物模式下必须进入显式禁用状态。若动物模式调用以下能力应直接报错：

- 行推进。
- 最小可见行调整。
- 顶部空槽崩塌。
- 危险线判定。
- 复活空间上移。

## 17. 边界情况

### 17.1 只剩一个直接支撑泡泡

命中该泡泡但未消除：

- 正常吸附。
- 新泡泡与原泡泡共同受支撑。
- 根据两颗泡泡的新惯量旋转。

消除该泡泡：

- 外围全部失去支撑。
- 本次结算立即掉落。
- 无受支撑泡泡时进入获救。

### 17.2 命中后整盘清空

- 保留碰撞得分和消除结果。
- 不启动旋转。
- 不创建空的旋转动画。
- 等待掉落和消除表现完成后获救。

### 17.3 射失

- 消耗发射数。
- 不新增泡泡。
- 不产生旋转。
- 不调用顶部吸附。
- 仍按完整发射周期判断球数耗尽。

### 17.4 暂停和恢复

暂停时冻结：

- 旋转物理时间。
- 掉落物理。
- 延迟特殊效果。
- 输入状态。

恢复后从保存的旋转起始角、已用时间和目标状态继续，禁止按现实经过时间直接跳到结束。

### 17.5 重开和退出

- 清空待处理冲量。
- 清空旋转事件。
- 销毁旋转泡泡节点。
- 解除掉落节点与旋转层关系。
- 清理动物 prefab 和短期资源引用。

## 18. 验收标准

### 18.1 配置

1. 顶部行完全为空的动物关卡可以通过校验。
2. 相同布局放在普通模式下因缺少顶部锚点而报错。
3. 动物格放置泡泡时直接报错。
4. 动物格放置特殊实体时直接报错。
5. 初始存在不连通动物的泡泡时直接报错。
6. 缺失任意必填旋转参数时直接报错。
7. 旋转包围圆越界时直接报错。
8. 动物模式配置虫洞、锁定球或漩涡时直接报错。

### 18.2 支撑

1. 动物六个邻接格是唯一支撑种子。
2. 顶部行泡泡不会因为位于第0行而获得支撑。
3. 删除单个桥接泡泡后，整个外围分支本次结算立即掉落。
4. 删除最后一个动物邻接泡泡后，所有外围泡泡一起掉落。
5. 无支撑泡泡不会残留到下一次发射。

### 18.3 旋转

1. 正对动物中心发射，旋转接近零。
2. 左右对称切向发射产生大小相近、方向相反的旋转。
3. 相同入射角下，外圈命中比内圈命中产生更大力矩。
4. 泡泡数量越多、分布越远，角速度越低。
5. 角速度和单次转角不会超过配置上限。
6. 棋盘停在任意角度，不会吸附到60°倍数。
7. 暂停和恢复不会改变最终角度。
8. 不同帧率下的最终角度保持一致。

### 18.4 碰撞与吸附

1. 任意旋转角下，预测碰撞泡泡与真实碰撞泡泡一致。
2. 任意旋转角下，预测吸附格与真实吸附格一致。
3. 墙壁反弹使用最终入射方向计算力矩。
4. 顶部射失不会产生顶部吸附。
5. 运行时找不到预测吸附格时直接暴露错误。
6. 动物保留格永远不能吸附泡泡。

### 18.5 掉落与表现

1. 掉落泡泡从旋转层脱离后不再跟随泡泡簇。
2. 掉落泡泡起点与脱离瞬间的世界坐标一致。
3. 顺时针和逆时针旋转产生方向正确的切向掉落速度。
4. 泡泡簇旋转期间不能再次发射。
5. 整盘清空后不播放空旋转。
6. 动物节点不随泡泡簇持续旋转。

### 18.6 胜负

1. 最后一组泡泡清除后进入动物获救流程。
2. 最后一个发射球完成获救时判定胜利，不进入球数耗尽。
3. 最后一个发射球未完成获救时，等旋转和掉落结束后进入球数耗尽。
4. 动物模式不会触发危险线失败。
5. 动物获救事件只能触发一次。

## 22. 设计结论

该玩法的关键不是“让棋盘节点转起来”，而是建立一套完整的动物锚点棋盘规则：

1. 动物是唯一支撑源。
2. 六边形格子拓扑保持不变。
3. 整个受支撑泡泡簇共享权威旋转角度。
4. 碰撞和吸附在旋转坐标系中保持严格一致。
5. 旋转强度由真实入射方向、命中距离和当前惯量共同决定。
6. 结构变化后立即重算动物支撑并完成同周期掉落。
7. 顶部支撑、棋盘推进、危险线和额外锚点在该模式中明确禁用。

只有同时完成配置、玩法状态、坐标变换、支撑、掉落、渲染、编辑器和生成包验证，才能认为动物救援玩法形成了完整闭环。
