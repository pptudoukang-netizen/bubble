# Cocos Creator 2.x MCP Server v1.0.4

## 安装说明

1. 将 cocos2x-mcp-server 文件夹复制到 Cocos Creator 2.x 项目的 `packages` 目录
2. 完全关闭 Cocos Creator，然后重新打开项目
3. 在扩展菜单中找到 "MCP Server"

## 使用配置

### Claude Desktop / Cursor
```json
{
  "mcpServers": {
    "cocos-creator-2x": {
      "type": "http",
      "url": "http://127.0.0.1:4000/mcp"
    }
  }
}
```
